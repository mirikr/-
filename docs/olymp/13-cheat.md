# Шпаргалка на утро

Одна страница перед олимпиадой: только то, что нужно помнить точно. Ничего нового — всё это есть в разделах.

## Формат

- Первый тур — **40 минут**, 12–15 заданий: меньше 3 минут на каждое. Второй — **60 минут**, одно развёрнутое задание. Каждый тур — до 100 баллов.
- Проверяют **только чистовик**. Ручка синяя или фиолетовая.
- Один элемент ответа — один балл: **нумеруй** аргументы и примеры.
- В суждениях ищи «всегда», «только», «любой», подмену понятия.

## Экономика: формулы

| Что | Формула |
|---|---|
| Выручка, прибыль | TR = P × Q; прибыль = TR − TC |
| Экономическая прибыль | выручка − явные − неявные издержки |
| Безубыточность | Q = FC : (P − AVC) |
| Равновесие | Qd = Qs |
| Эластичность | % ΔQ : % ΔP; больше 1 — эластичный |
| ВВП | C + I + G + Xn |
| Реальный ВВП | номинальный : индекс цен |
| Инфляция | (I₁ − I₀) : I₀ × 100 % |
| Уравнение обмена | MV = PQ |
| Мультипликатор | 1 : норма резервов |
| Проценты | простые P(1 + rn); сложные P(1 + r)ⁿ |
| Безработица | безработные : (занятые + безработные) |
| Бюджет | сальдо = доходы − расходы |
| Изменение в % | (новое − старое) : старое × 100 % |

- Цена меняет **величину** спроса; остальное сдвигает кривую.
- Процентный пункт ≠ процент. Студент-очник и пенсионер — не безработные.
- НДФЛ: 13 % до 2,4 млн, дальше 15, 18, 20, 22 % — только с превышения.
- Фьючерс — обязательство, опцион — право. Вклады застрахованы до 1,4 млн ₽.

## Кто что делает

| Совет Федерации | Государственная Дума | Президент |
|---|---|---|
| отрешает Президента | выдвигает обвинение | помилование |
| назначает судей КС и ВС | утверждает Председателя Правительства | назначает Председателя Правительства после утверждения Думой |
| назначает выборы Президента | назначает главу Центробанка | Генерального прокурора — после консультаций с Советом Федерации |
| утверждает военное и чрезвычайное положение | амнистия | вводит военное и чрезвычайное положение |
| границы между субъектами | Уполномоченный по правам человека | распускает Думу, назначает референдум |

- Исключительное ведение: уголовное, гражданское, процессуальное право, оборона, внешняя политика, эмиссия. Совместное: административное, трудовое, семейное, жилищное, земельное; «общие принципы», «координация».
- Не ограничиваются при чрезвычайном положении: жизнь, достоинство, частная жизнь и тайна, свобода совести, жилище, судебные гарантии (статьи 46–54).

## Право: возрасты

| Возраст | Что наступает |
|---|---|
| 6 | мелкие бытовые сделки |
| 10 | учёт мнения ребёнка |
| 14 | распоряжение заработком и стипендией, вклады, авторские права; уголовная ответственность за ряд преступлений; работа с согласия родителя; сам отвечает за вред; паспорт; молодёжь |
| 15 | лёгкий труд; отчисление из школы как взыскание |
| 16 | трудовой договор; административная и общая уголовная ответственность; эмансипация; брак по разрешению |
| 18 | полная дееспособность, избирательное право, призыв |

- Обмен качественного товара — 14 дней; возврат технически сложного — 15 дней; гарантия не установлена — 2 года.
- Письменная форма сделок граждан — свыше 10 000 ₽. Исковая давность — 3 года. Наследство — 6 месяцев.
- Взыскания работнику: замечание, выговор, увольнение. Штрафа нет.

## Состав правонарушения

| Элемент | Вопрос |
|---|---|
| Объект | на что посягнули — отношения, не вещь |
| Объективная сторона | что сделано: деяние, последствия, связь; способ, место, время |
| Субъект | кто: возраст, вменяемость |
| Субъективная сторона | вина, мотив, цель |

Вина: **прямой умысел** — желал; **косвенный** — допускал, безразличен; **легкомыслие** — рассчитывал избежать; **небрежность** — не предвидел, хотя должен был.

## Политология и социология

- Формы правления: президентская (США), парламентская (Германия, Италия), смешанная (Россия, Франция); монархии — абсолютная, дуалистическая, парламентская.
- Режимы: демократия, авторитаризм, тоталитаризм. Легальность ≠ легитимность.
- Господство по Веберу: традиционное, харизматическое, рационально-легальное.
- Избирательные системы: мажоритарная, пропорциональная, смешанная. Дума — смешанная, барьер 5 %.
- Артикуляция — выразить интересы; агрегирование — свести в программу.
- Мертон: конформизм, инновация, ритуализм, ретритизм, мятеж.
- Мобильность: вертикальная и горизонтальная; лифты — армия, церковь, школа, брак.
- Безработица: фрикционная, структурная, циклическая, сезонная.

## Второй тур: схема ответа

1. Позиция автора — своими словами: «автор считает, что…, потому что…».
2. Аргументы — по номерам; каждый = тезис + объяснение.
3. Примеры — конкретные: страна, год, закон, явление.
4. Определение — род + видовые отличия.
5. Проект: проблема → цель → целевая группа → меры → ресурсы → результат → риски.
