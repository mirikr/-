# Экономика

Основы и формулы. Модели с расчётами (излишки, налоги, эластичность, монополия, кругооборот, валютный курс) с разобранными задачами — в следующем разделе, «Экономика: углубление».

## Обозначения

Буквы в формулах — первые буквы английских терминов. Их используют и в задачах олимпиад, и в учебниках, поэтому их стоит узнавать сразу.

| Буква | Что означает | От английского |
|---|---|---|
| **P** | цена товара (в макроэкономике — общий уровень цен) | price |
| **Q** | количество товара, объём выпуска | quantity |
| **Qd** | величина спроса — сколько купят при данной цене | quantity demanded |
| **Qs** | величина предложения — сколько продадут при данной цене | quantity supplied |
| **D**, **S** | кривая спроса и кривая предложения | demand, supply |
| **E**, **Ed** | эластичность (спроса по цене) | elasticity |
| **Δ** (дельта) | изменение величины: ΔP — на сколько изменилась цена | — |
| **TR** | общая выручка | total revenue |
| **MR** | предельная выручка — прирост выручки от ещё одной проданной единицы | marginal revenue |
| **TC** | общие издержки | total cost |
| **FC** | постоянные издержки — не зависят от объёма | fixed cost |
| **VC** | переменные издержки — растут с объёмом | variable cost |
| **ATC** | средние общие издержки — на единицу товара | average total cost |
| **AFC**, **AVC** | средние постоянные и средние переменные издержки | average fixed / variable cost |
| **MC** | предельные издержки — прирост издержек на ещё одну единицу | marginal cost |
| **π** (пи) | прибыль; в макроэкономике той же буквой обозначают инфляцию | profit |
| **ВВП**, **Y** | валовой внутренний продукт, совокупный доход страны (Y — просто принятая буква для дохода) | gross domestic product |
| **C** | потребительские расходы домохозяйств | consumption |
| **I** | инвестиции (покупка оборудования, строительство); в формулах про цены I — индекс цен | investment, index |
| **G** | государственные закупки товаров и услуг | government |
| **Xn**, **NX** | чистый экспорт = экспорт − импорт | net exports |
| **Ex**, **Im** | экспорт и импорт | export, import |
| **M** | денежная масса — сколько денег в экономике | money |
| **V** | скорость обращения денег — сколько раз за год рубль переходит из рук в руки | velocity |
| **r** | процентная ставка (в долях: 10 % = 0,1) | rate |
| **rr** | норма обязательных резервов банков (в долях) | required reserves |
| **n** | число лет (периодов) | number |
| **S** (в процентах) | сумма вклада в конце срока; в макроэкономике S — сбережения | sum, savings |
| **P** (в процентах) | первоначальная сумма вклада | principal |
| **U** | число безработных | unemployed |
| **E** (на рынке труда) | число занятых | employed |
| **L** | рабочая сила, иногда — труд как фактор | labour |
| **K** | капитал | от немецкого Kapital (так обозначал Маркс) |
| **T** | налоги | taxes |

Одна и та же буква иногда значит разное: **P** — цена товара и первоначальная сумма вклада, **S** — предложение и сбережения, **E** — эластичность и занятые, **I** — инвестиции и индекс цен. Смысл всегда виден из формулы и условия.

## Основы

**Экономика** — хозяйство (производство, распределение, обмен, потребление) и наука о выборе в условиях ограниченности ресурсов. **Микроэкономика** изучает потребителей, фирмы, отдельные рынки; **макроэкономика** — экономику в целом.

**Главная проблема** — ограниченность ресурсов при безграничных потребностях. Три вопроса: что производить, как, для кого.

**Факторы производства и доходы:**

| Фактор | Доход |
|---|---|
| Труд | заработная плата |
| Земля (природные ресурсы) | рента |
| Капитал (физический: здания, оборудование) | процент |
| Предпринимательские способности | прибыль |
| Информация (в современных классификациях) | роялти |

Деньги сами по себе — не фактор производства (финансовый капитал превращается в реальный).

**Альтернативная стоимость (издержки упущенных возможностей)** — ценность лучшей из отвергнутых альтернатив.

**Кривая производственных возможностей (КПВ)** — все сочетания двух благ при полном и эффективном использовании ресурсов. Точка на кривой — эффективно; внутри — ресурсы недоиспользованы (безработица); снаружи — недостижимо. Кривая выпукла из-за **закона возрастающих альтернативных издержек**. Сдвиг вправо — экономический рост (больше ресурсов, лучше технологии). Альтернативная стоимость единицы блага X = сколько Y теряем.

**Экономические системы:** традиционная (обычай), командная (плановая: государственная собственность, директивные цены), рыночная (частная собственность, конкуренция, свободные цены), смешанная.

**Собственность:** частная, государственная, муниципальная и иные формы (так в Конституции). Правомочия собственника: владение, пользование, распоряжение. **Приватизация** и **национализация**.

**Школы — минимум:** **меркантилизм** — богатство в золоте, протекционизм, положительное торговое сальдо; **физиократы** (Ф. Кенэ) — источник богатства в земледелии; **классики** (А. Смит — «невидимая рука», Д. Рикардо — сравнительное преимущество); **марксизм** — прибавочная стоимость; **маржинализм** — предельная полезность; **кейнсианство** (Дж. М. Кейнс) — совокупный спрос, активная роль государства, бюджетная политика; **монетаризм** (М. Фридман) — главное количество денег, основной инструмент — денежно-кредитная политика; **институционализм** (Т. Веблен, Р. Коуз, Д. Норт) — правила и трансакционные издержки.

## Спрос и предложение

**Закон спроса:** при прочих равных чем выше цена, тем меньше величина спроса. **Закон предложения:** чем выше цена, тем больше величина предложения.

Изменение **цены самого товара** — движение **вдоль** кривой (меняется *величина* спроса или предложения). **Неценовые факторы** сдвигают саму кривую.

| Сдвигает спрос | Сдвигает предложение |
|---|---|
| доходы потребителей | цены ресурсов (издержки) |
| вкусы, мода, реклама | технологии |
| цены заменителей и дополняющих товаров | налоги и субсидии |
| ожидания | ожидания производителей |
| число покупателей | число продавцов |

- **Нормальный товар:** доход растёт — спрос растёт. **Инфериорный (низшей категории):** доход растёт — спрос падает.
- **Заменители (субституты):** цена одного растёт — спрос на другой растёт. **Дополняющие (комплементы):** цена одного растёт — спрос на другой падает.
- Исключения из закона спроса: товар Гиффена, эффект Веблена (демонстративное потребление).

**Равновесие:** Qd = Qs. Цена выше равновесной — **избыток** (Qs > Qd); ниже — **дефицит** (Qd > Qs). Потолок цен ниже равновесия создаёт дефицит; минимальная цена выше равновесия — избыток.

**Пример.** Qd = 100 − 2P, Qs = 3P − 50. Равновесие: 100 − 2P = 3P − 50 → P = 30, Q = 40. При цене 20: Qd = 60, Qs = 10 — дефицит 50.

**Эластичность спроса по цене** = % изменения величины спроса : % изменения цены (по модулю). Больше 1 — эластичный; меньше 1 — неэластичный; равна 1 — единичная. При эластичном спросе снижение цены **увеличивает выручку**, при неэластичном — уменьшает. Спрос эластичнее, когда есть заменители, товар не первой необходимости, велика доля в бюджете, длинный период.

## Фирма: издержки и прибыль

- **Выручка** TR = P × Q.
- **Постоянные издержки** FC не зависят от объёма (аренда, оклады управленцев, проценты по кредиту, амортизация, страховка). **Переменные** VC зависят (сырьё, сдельная зарплата, энергия на производство, транспорт). TC = FC + VC.
- **Средние:** ATC = TC / Q, AFC = FC / Q, AVC = VC / Q. **Предельные** MC — прирост издержек при выпуске ещё одной единицы.
- **Бухгалтерские (явные) издержки** — фактические платежи. **Экономические** = бухгалтерские + **неявные** (упущенная зарплата, упущенный процент на свой капитал, упущенная аренда своего помещения).
- **Бухгалтерская прибыль** = выручка − бухгалтерские издержки. **Экономическая прибыль** = выручка − экономические издержки. Экономическая всегда не больше бухгалтерской.
- **Рентабельность** = прибыль : издержки (или : выручку) × 100 %.
- **Точка безубыточности:** Q = FC : (P − AVC).
- Правило максимизации прибыли: MR = MC.

**Пример.** Марк ушёл с работы с зарплатой 600 тыс. в год, вложил свои 1 млн (банк давал 10 %), платит аренду 300 тыс. и материалы 200 тыс., выручка 1,5 млн. Бухгалтерские издержки — 500 тыс., неявные — 600 + 100 = 700 тыс., экономические — 1,2 млн. Бухгалтерская прибыль — 1 млн, экономическая — 300 тыс.

**Производительность труда** — выпуск на работника или в час. Растёт от разделения труда, технологий, квалификации.

**Организационно-правовые формы** (Гражданский кодекс):

- **Коммерческие:** хозяйственные товарищества (полное, на вере), хозяйственные общества (ООО, АО — публичное и непубличное), хозяйственные партнёрства, производственные кооперативы, крестьянские (фермерские) хозяйства, государственные и муниципальные унитарные предприятия.
- **Некоммерческие:** потребительские кооперативы, общественные организации, ассоциации (союзы), фонды, учреждения, религиозные организации, ТСН и другие.
- **Индивидуальный предприниматель** — не юридическое лицо, отвечает всем своим имуществом. **Самозанятый** платит налог на профессиональный доход.

**Финансирование:** внутренние источники (прибыль, амортизация) и внешние (кредит, выпуск акций и облигаций, бюджетные субсидии).

## Рыночные структуры

| Структура | Число фирм | Товар | Вход на рынок | Власть над ценой |
|---|---|---|---|---|
| Совершенная конкуренция | очень много | однородный | свободный | нет |
| Монополистическая конкуренция | много | дифференцированный | почти свободный | небольшая |
| Олигополия | несколько | любой | высокие барьеры | значительная, взаимозависимость |
| Монополия | одна | уникальный | закрыт | полная |

**Монопсония** — один покупатель. **Естественная монополия** — когда одна фирма обслуживает рынок дешевле нескольких (сети). **Картель** — сговор о ценах и объёмах. Государство защищает конкуренцию: антимонопольное законодательство, ФАС.

## Макроэкономика: ВВП

**ВВП** — рыночная стоимость всех **конечных** товаров и услуг, произведённых **на территории страны** за год. **ВНП (ВНД)** — произведённых **резидентами** страны, где бы они ни находились.

Не входят: промежуточная продукция (двойной счёт), перепродажа подержанного, финансовые сделки, трансферты, домашний труд, теневая экономика (оценивается отдельно).

**По расходам:** ВВП = C + I + G + Xn (потребление + инвестиции + государственные закупки + чистый экспорт).

**Номинальный ВВП** — в текущих ценах; **реальный** — в ценах базового года. **Дефлятор** = номинальный : реальный. Реальный = номинальный : индекс цен.

**Экономический рост** — увеличение реального ВВП (или на душу населения). **Экстенсивный** — за счёт количества ресурсов; **интенсивный** — за счёт качества и эффективности. **Экономический цикл:** подъём → пик → спад (рецессия) → дно → оживление.

## Инфляция

**Инфляция** — устойчивый рост общего уровня цен; покупательная способность денег падает. **Дефляция** — снижение цен; **дезинфляция** — замедление роста цен; **стагфляция** — инфляция при спаде.

- **Темп инфляции** = (индекс цен нового года − индекс прошлого) : индекс прошлого × 100 %.
- По темпам: ползучая (до ~10 % в год), галопирующая, гиперинфляция.
- По причинам: **инфляция спроса** («слишком много денег») и **инфляция издержек** (рост цен ресурсов).
- **Реальный доход** ≈ номинальный рост − инфляция. Точно: (1 + номинальный) : (1 + инфляция) − 1.
- Выигрывают заёмщики с фиксированной ставкой; проигрывают кредиторы, люди с фиксированными доходами, держатели наличных.
- При гиперинфляции деньги перестают работать — переходят к бартеру.

## Деньги и банки

**Функции денег:** мера стоимости, средство обращения, средство платежа (при отсрочке), средство накопления, мировые деньги. **Ликвидность** — способность быстро превращаться в платёжное средство без потери стоимости; наличные — самые ликвидные.

**Уравнение обмена (И. Фишер):** M × V = P × Q, где M — денежная масса, V — скорость обращения, P — уровень цен, Q — реальный объём выпуска. P × Q — номинальный ВВП.

**Пример из олимпиады.** Номинальный ВВП 3600, денежная масса 400 → V = 9. Цены выросли так, что прошлогодние цены составляют 0,8 от нынешних: реальный ВВП = 3600 × 0,8 = 2880; инфляция = (1 − 0,8) : 0,8 = 25 %.

**Банковская система России — двухуровневая:** Центральный банк (Банк России) и коммерческие банки.

**Функции Банка России:** эмиссия наличных, защита и обеспечение устойчивости рубля (конституционная функция, осуществляется независимо от других органов власти), ключевая ставка, лицензирование и надзор, хранение резервов, кредитор последней инстанции, банк правительства, регулирование финансового рынка.

**Денежно-кредитная политика:**

| Инструмент | Сдерживающая политика («дорогие деньги», против инфляции) | Стимулирующая («дешёвые деньги») |
|---|---|---|
| Ключевая ставка | повышают | снижают |
| Норма обязательных резервов | повышают | снижают |
| Операции на открытом рынке | продают государственные ценные бумаги | покупают |

**Банковский мультипликатор** = 1 : норма резервов. При норме 10 % вклад 100 может создать до 1000 денег.

**Проценты.** Простые: S = P × (1 + r × n). Сложные: S = P × (1 + r)ⁿ. Вклад 100 тыс. под 10 % на 2 года: простые — 120 тыс., сложные — 121 тыс.

**Операции банков:** пассивные (привлечение вкладов), активные (кредиты). Принципы кредита: срочность, платность, возвратность, обеспеченность. Вклады граждан застрахованы государством (до 1,4 млн рублей в одном банке).

## Финансовые рынки и личные финансы

- **Акция** — долевая бумага: доля в капитале, право на дивиденд и участие в управлении (обыкновенная — голос, привилегированная — фиксированный дивиденд обычно без голоса). Риск выше.
- **Облигация** — долговая бумага: возврат номинала и купон. У государственных (ОФЗ) риск ниже. Государство выпускает облигации, чтобы занять деньги на покрытие дефицита бюджета; изъятие денег из обращения помогает сдерживать инфляцию.
- **Производные инструменты (деривативы):** **фьючерс** — **обязательство** купить или продать в будущем по заранее оговорённой цене; **опцион** — **право** без обязанности. Используются для страхования рисков (хеджирования) и спекуляций.
- **Вексель**, **чек**, **закладная**, **инвестиционный пай** — тоже ценные бумаги.
- **Диверсификация** — распределение вложений между разными активами, отраслями, странами (а не просто «акции нескольких компаний»).
- Правило: **чем выше ожидаемая доходность, тем выше риск**. Обещание высокой гарантированной доходности — признак **финансовой пирамиды**.
- **Показатель долговой нагрузки (ПДН)** — доля **дохода заёмщика**, уходящая на платежи по кредитам.
- **Полная стоимость кредита**, **кредитная история**, **период охлаждения**, **самозапрет на кредиты** — понятия финансовой безопасности. **Фишинг**, **социальная инженерия** — способы мошенничества.
- **Страхование:** страховщик, страхователь, страховая премия (платёж), страховая сумма, страховой случай.

## Рынок труда

- **Рабочая сила** (экономически активное население) = занятые + безработные. **Безработный** — трудоспособный, не имеет работы, ищет её и готов приступить.
- Не входят в рабочую силу: студенты-очники, пенсионеры, домохозяйки, отчаявшиеся искать.
- **Уровень безработицы** = безработные : рабочая сила × 100 %. **Уровень занятости** = занятые : рабочая сила (или : взрослое население — смотри условие).

| Вид | Причина |
|---|---|
| Фрикционная | поиск или смена работы, выход на рынок впервые |
| Структурная | изменение технологий и структуры спроса, устаревание профессий |
| Циклическая | спад экономики |
| Сезонная | сезонный характер работ |

**Естественная безработица** = фрикционная + структурная; **полная занятость** — когда циклической нет. **Закон Оукена:** каждый процент безработицы сверх естественного — потеря примерно 2–2,5 % ВВП.

**Пример.** 100 тыс. жителей: 60 тыс. заняты, 5 тыс. безработных, остальные вне рабочей силы. Уровень безработицы = 5 : 65 = 7,7 %. Если 2 тыс. занятых уйдут на пенсию: 5 : 63 = 7,9 % — выросла на 0,2 **процентного пункта**. Если те же 2 тыс. уволятся и станут искать работу: 7 : 65 = 10,8 %.

**Заработная плата:** номинальная и реальная; повременная и сдельная. **МРОТ** устанавливается федеральным законом и по Конституции не может быть ниже прожиточного минимума трудоспособного населения. **Профсоюзы** защищают интересы работников.

## Государство в экономике

**Зачем:** производство **общественных благ** (неисключаемость и неконкурентность: оборона, освещение улиц; отсюда «проблема безбилетника»), компенсация **внешних эффектов** (отрицательные — загрязнение — облагают налогом; положительные — образование — субсидируют), защита конкуренции, перераспределение доходов, стабилизация.

**Налоги** — обязательные безвозмездные платежи. Функции: фискальная, распределительная, регулирующая (стимулирующая), контрольная.

- **Прямые** — с дохода или имущества (НДФЛ, налог на прибыль, на имущество, земельный, транспортный). **Косвенные** — в цене товара (НДС, акцизы, таможенные пошлины).
- По уровням: **федеральные** (НДС, акцизы, НДФЛ, налог на прибыль, НДПИ, водный, госпошлина, **налог на игорный бизнес — федеральный с 1 января 2026 года**, до этого был региональным), **региональные** (на имущество организаций, транспортный), **местные** (земельный, на имущество физических лиц, торговый сбор, туристический).
- Системы: **пропорциональная** (ставка одна), **прогрессивная** (ставка растёт с доходом), **регрессивная** (доля платежа в доходе падает с ростом дохода).

**НДФЛ в России с 2025 года — прогрессивный, пять ступеней:**

| Доход за год | Ставка на часть сверх порога |
|---|---|
| до 2,4 млн ₽ | 13 % |
| 2,4–5 млн | 15 % |
| 5–20 млн | 18 % |
| 20–50 млн | 20 % |
| свыше 50 млн | 22 % |

Повышенная ставка применяется **только к превышению**. Доход 3 млн: 2,4 млн × 13 % + 0,6 млн × 15 % = 312 + 90 = 402 тыс. Налог на прибыль организаций с 2025 года — 25 %. Основная ставка НДС — 22 % с 2026 года (до этого 20 %); льготные — 10 % и 0 %.

**Кривая Лаффера:** после определённого уровня рост ставок снижает поступления.

**Государственный бюджет** — план доходов и расходов на год; принимается в форме федерального закона (проект вносит Правительство, принимает Государственная Дума, одобряет Совет Федерации, подписывает Президент).

- **Дефицит:** расходы > доходов. **Профицит:** доходы > расходов. **Сальдо** = доходы − расходы.
- Покрытие дефицита: займы (внутренние и внешние), резервные фонды, эмиссия (ведёт к инфляции).
- **Государственный долг** — накопленная задолженность. Долг на конец года = долг на начало + дефицит.
- Расходы: закупки, **трансферты** (пенсии, пособия, стипендии — безвозмездные выплаты), обслуживание долга.

**Пример из олимпиады.** Доходы 920, расходы 1050, ВВП 4000. Дефицит 130, или 3,25 % ВВП. Сократить дефицит на 20 % без изменения доходов: новый дефицит 104, расходы 1024.

**Бюджетно-налоговая (фискальная) политика:** стимулирующая — снижать налоги, увеличивать расходы (при спаде); сдерживающая — наоборот (при «перегреве»).

## Мировая экономика

- **Международное разделение труда**, специализация. **Абсолютное преимущество** (А. Смит) — производим с меньшими затратами. **Сравнительное** (Д. Рикардо) — с меньшей альтернативной стоимостью; торговля выгодна, даже если страна во всём абсолютно слабее.
- **Протекционизм** — защита своих производителей: пошлины, квоты, эмбарго, субсидии, технические барьеры. **Фритредерство** — свободная торговля.
- **Торговый баланс** = экспорт − импорт товаров (положительное сальдо — экспорт больше). **Платёжный баланс** — все операции страны с остальным миром.
- **Валютный курс.** Удорожание национальной валюты удешевляет импорт и бьёт по экспортёрам; **девальвация** (ослабление) выгодна экспортёрам, но разгоняет цены на импорт. Режимы: фиксированный и плавающий.
- **Международные резервы** Центрального банка расходуются на покрытие дефицита валюты.

**Пример.** Экспорт 500 млн долларов, импорт 620 млн: торговый баланс −120 млн. При курсе 80 за доллар для покрытия нужно 9600 млн национальной валюты. Резервы 400 млн после покрытия — 280 млн.

- **Интеграция:** зона свободной торговли → таможенный союз → общий рынок → экономический и валютный союз. Примеры: ЕС, ЕАЭС, БРИКС (объединение, а не интеграционный союз), ВТО, МВФ, Всемирный банк.

## Формулы на один листок

| Что считаем | Формула | Что значат буквы и как читать |
|---|---|---|
| Выручка | TR = P × Q | выручка равна цене, умноженной на количество проданного |
| Прибыль | π = TR − TC | выручка минус все издержки |
| Общие издержки | TC = FC + VC | постоянные плюс переменные |
| Средние издержки | ATC = TC : Q | сколько стоит в среднем одна единица товара |
| Предельные издержки | MC = ΔTC : ΔQ | на сколько вырастут издержки, если выпустить ещё одну единицу |
| Экономическая прибыль | TR − (явные + неявные издержки) | неявные — упущенная зарплата, процент на свои деньги, аренда своего помещения |
| Безубыточность | Q = FC : (P − AVC) | сколько единиц продать, чтобы покрыть постоянные издержки: каждая единица приносит «сверх своих затрат» P − AVC |
| Рентабельность | π : TC × 100 % | сколько процентов прибыли приносит каждый рубль затрат |
| Максимум прибыли | MR = MC | выпускать, пока ещё одна единица приносит не меньше, чем стоит |
| Эластичность | Ed = % ΔQ : % ΔP | на сколько процентов изменится величина спроса при изменении цены на 1 %; |Ed| > 1 — спрос эластичный |
| Равновесие | Qd = Qs | сколько хотят купить, столько готовы продать; отсюда находят равновесную цену |
| ВВП по расходам | Y = C + I + G + Xn | потребление + инвестиции + государственные закупки + чистый экспорт |
| Реальный ВВП | номинальный ВВП : индекс цен | ВВП в ценах базового года; индекс цен 1,25 значит, что цены выросли на 25 % |
| Темп инфляции | (I₁ − I₀) : I₀ × 100 % | I₀ — индекс цен прошлого периода, I₁ — нынешнего |
| Уравнение обмена | M × V = P × Q | денег × сколько раз они оборачиваются = уровень цен × реальный выпуск; P × Q — номинальный ВВП |
| Банковский мультипликатор | 1 : rr | во сколько раз вклад может увеличить денежную массу; при rr = 0,1 — в 10 раз |
| Простые проценты | S = P × (1 + r × n) | проценты каждый год только на первоначальную сумму |
| Сложные проценты | S = P × (1 + r)ⁿ | проценты начисляются и на уже начисленные проценты |
| Уровень безработицы | U : (E + U) × 100 % | безработные делить на рабочую силу (занятые + безработные) |
| Сальдо бюджета | доходы − расходы | больше нуля — профицит, меньше — дефицит |
| Торговый баланс | экспорт − импорт | больше нуля — положительное сальдо |
| Изменение в % | (новое − старое) : старое × 100 % | делить всегда на **старое** значение |

## Ловушки раздела

- «Спрос» и «величина спроса» — разное: цена меняет величину, остальное сдвигает кривую.
- Деньги и акции — не фактор производства «капитал».
- Проценты по кредиту и аренда — постоянные издержки; сырьё — переменные.
- Студент-очник и пенсионер — не безработные.
- Трансферты и покупка подержанной машины в ВВП не входят.
- Фьючерс — обязательство, опцион — право.
- Процентный пункт ≠ процент: рост с 5 % до 6 % — это на 1 п. п., но на 20 %.
- Положительное торговое сальдо — цель меркантилизма.
- Эмиссия денег и эмиссия ценных бумаг — разные вещи: наличные выпускает только Банк России, ценные бумаги — государство и компании.
