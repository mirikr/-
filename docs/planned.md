# Что задумано, но ещё не сделано

Список живёт в репозитории, а не в голове и не в переписке: сессия кончается,
а задумки остаются. Сделанное отсюда убирается.

## Поиск задания по номеру

В разделе «Поиск» должен находиться номер задания из банка ФИПИ — тот самый
код, который подписан у каждого задания в тренажёре (например, `0810F0`).
Сейчас поиск ищет по своим записям — урокам, конспектам, домашке, событиям —
а по набору заданий не ищет вовсе, хотя именно по коду задание и договорились
искать: он для того и показан.

Что нужно:

- искать по номеру целиком и по началу, без учёта регистра (`0810f0`, `0810`);
- заодно по тексту условия, чтобы номер не приходилось помнить;
- из найденного открывать задание в тренажёре, а не просто показывать строчку;
- набор заданий грузится отдельным куском (`src/trainer.jsx` через `lazy`),
  поэтому поиску хватит номеров и коротких строк — тянуть ради поиска
  полтора мегабайта условий нельзя. Похоже, рядом с `src/fipi-index.js`
  нужен такой же лёгкий список «номер — предмет — начало условия».

## Набор заданий стоит делить по предметам

Кусок с заданиями вырос до 5,9 МБ (2,7 МБ в сжатом виде) и грузится целиком,
как только открывают тренажёр, — даже если человек решает одно обществознание.
Дальше он будет только расти. Напрашивается по куску на предмет: тогда
загружается только то, что открыли, а остальное подтягивается при переключении.
