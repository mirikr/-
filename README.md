# Ежедневник обществоведа

Личный планировщик подготовки к экзамену и олимпиаде по обществознанию
(право, экономика, политология, социология, философия) и истории.
Веб-приложение на React, ставится на экран «Домой» на iPhone и синхронизируется
между устройствами.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # посмотреть собранную версию
```

Без настроек приложение работает сразу — данные хранятся в браузере этого
устройства. Чтобы записи были одни и те же на ноутбуке и на телефоне, нужно
подключить Supabase: `docs/supabase-setup.md`. Ключи берутся из `.env.local`
(шаблон — в `.env.example`); в репозиторий они не коммитятся.

## Разделы приложения

1. **КПВ (распределение времени)** — цель по каждому дню недели, часы на предмет,
   проверка «хватит ли времени до дедлайна», предупреждение об уклоне,
   парный график план/факт по реально потраченным часам.
2. **Самостоятельное изучение** — предметы, уроки со ссылками, длительностью
   и заметками; отметка «пройдено» и заметка со временем сами пишутся в дневник.
3. **Лицей КЭО — расписание** — по дням недели, с временем, кабинетом и учителем.
4. **Дневник занятий** — календарь-теплокарта по выполнению дневной цели,
   записи за день и домашние задания с файлами и напоминаниями.
5. **Перенос данных между устройствами** — ручной экспорт/импорт JSON.

## Как хранятся данные

Каждое изменение сначала попадает в `localStorage` (приложение работает офлайн),
а затем уходит в Supabase с меткой времени. При открытии приложения обе копии
сравниваются, и более свежая побеждает. Подробнее — в `docs/project-map.md`.

## Публикация

`.github/workflows/deploy.yml` собирает и выкладывает приложение на GitHub Pages
при пуше в `main`. Ключи Supabase берутся из секретов репозитория
`VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`; без них сборка тоже проходит,
приложение просто остаётся локальным.

Важно: **GitHub Pages для приватного репозитория доступны только на платных
тарифах**. Пока репозиторий приватный и тариф бесплатный, вариантов два:

- выложить на Vercel или Netlify — они бесплатно собирают и приватные
  репозитории, ключи прописываются в настройках проекта;
- либо сделать репозиторий публичным. Тогда стоит заодно закрыть свободную
  регистрацию в Supabase (Authentication → Sign Ups), чтобы аккаунты в вашем
  проекте не заводили посторонние.

## Важно при доработке

- `STORAGE_KEY = "planner-state-v5"` менять нельзя — это единственное, что
  связывает пользователя с уже сохранёнными данными.
- Новые поля добавляются только опционально, со значением по умолчанию при
  отсутствии, чтобы старые сохранения не ломались.
