# Тесты ВсОШ

`src/vosh/vosh-society.js` и опись `src/vosh-index.js` собираются отсюда:

```
node tools/build-vosh.mjs
```

## Откуда задания

Из опубликованных «заданий и критериев оценивания» школьного и муниципального
этапов (Москва). Переносятся только задания, которые проверяются по ключу:
«да/нет», выбор, соответствие, классификация изображений, пропуски в тексте,
числа и термины. Развёрнутые (эссе, объяснения, примеры) не переносятся.

## Как устроен файл олимпиады

`society/<год>-<этап>-<класс>.mjs`, например `2425-mun-10.mjs`. Ключи пишутся
так же, как в критериях:

- `yesno` — `answer: "да нет да нет да"`;
- `multi` — `answer: "2, 3, 4"`, `per` за верный, `penalty` за неверный, `limit` —
  больше скольких отметок ноль; `over: true` — штраф только за пункты сверх
  числа верных; `exact: true` + `points` — только точное совпадение;
  `alt` — запасной ключ, если в опубликованном опечатка (с `note`);
- `one` — один вариант;
- `match` — `answer: "4 1 2 1 3 4"` по порядку позиций; `8/1` — подходит любой;
- `matchmany` — `answer: "III, IV | VII | I"`;
- `groups` — `answer: "АВЕ | БГД"`; `extra: true` — есть лишние изображения;
  если в условии «к группе 1 относится А», номера групп фиксированы;
- `gaps` — текст с пропусками `(А)`, `(Б)`, ответы по порядку пропусков;
- `short` — строка, `accept` — другие верные записи.

Длинные тексты лежат в `society/texts/*.txt` и подключаются `txt("имя")`,
картинки — в `public/vosh/*.webp` и подключаются `img("имя", "подпись")`.

Сборщик сверяет ключи с вариантами, число ответов с числом пунктов и наличие
картинок; при любой ошибке набор не собирается. Итог по олимпиаде печатается —
у школьных этапов сумма баллов должна совпасть с максимумом за работу.
