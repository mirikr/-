# Сборка набора заданий

`src/fipi-bank.js` собирается отсюда, руками его править не нужно.

## Откуда берутся задания

Со страницы открытого банка ФИПИ их снимает сборщик — небольшой скрипт, который
запускается прямо на странице банка из консоли или закладкой. Он сохраняет
условие вместе с разметкой, номер задания, раздел кодификатора, тип ответа и
картинки, а потом отдаёт всё одним файлом.

Правильных ответов банк не отдаёт: его страница отправляет ответ на сервер и
получает в ответ только «верно» или «неверно». Поэтому ключи решены нами и лежат
в `answers/` — по файлу на предмет. У каждого ключа есть разбор, а у неуверенных
— пометка, которая потом видна в приложении.

## Как пересобрать

```
FIPI_DIR=<папка с выгрузками сборщика> node tools/build-bank.mjs
```

Нужен `playwright` с Chromium: разметка условий разбирается настоящим браузером.
Если они лежат не в стандартном месте, путь передаётся переменными
`PLAYWRIGHT_MODULE` и `CHROMIUM_PATH`.

Сборка сама ругается, если разметка потеряла текст условия: однажды вместе с
полями ввода из неё вылетала вся таблица, а с ней и все варианты ответа.

## Что делает `clean-body.mjs`

Вынимает из снимка страницы саму разметку условия и чистит её: убирает шапку с
кнопкой ответа, формы, скрипты и поля ввода, вшивает картинки вместо ссылок на
чужой сайт и оставляет только знакомые теги. Два столбца задания на соответствие
переписывает из таблицы в колонки, чтобы на телефоне шапка осталась при своём
списке, а таблицы с данными помечает — им в приложении рисуется сетка.
